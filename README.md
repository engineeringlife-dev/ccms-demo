# CCMS 互動概念展示

CCMS（營造協同管理系統）的獨立前端展示，供介紹產品構想與試用流程。

## 展示內容

- 手機現場：預設回報 → 草稿確認與指派 → 班組承接 → 完成回報 → 人工驗收通過或退回。
- 管理總覽：與手機共享本分頁狀態、搜尋與狀態篩選、虛構統計、操作歷程。
- 開發藍圖：依《CCMS 開發路線圖 草案 v0.1》（2026-10-22）呈現第 0 至 7 階段及完成門檻。
- 響應式排版、鍵盤操作、明確欄位標籤與隱私界線。

## 重要限制

**本頁不是正式系統。全部工地、班組、工作與圖形證據均為虛構。**

- 沒有後端、帳號登入、真正 AI 分析、LINE 整合、外部通知或群組轉送。
- 不讀取或上傳照片；證據只是預設的 SVG 圖形示意。
- 不使用 Cookie、localStorage、分析追蹤或外部資源。互動狀態只保留在分頁記憶體；重新整理或重設即清除。
- 角色切換不是正式權限控管，歷程不是不可竄改稽核。
- 不應輸入真實姓名、電話、地址、工程機密或其他個人資料。
- 規劃方向不等於目前已實作、測試通過、人工驗收或正式上線。
- 正式產品仍需權限隔離、附件檢查、備份還原、真實整合與跨平台驗證。

## 使用

靜態檔案位於儲存庫根目錄，不需要套件安裝或建置。

本機直接開啟 `index.html`，或透過任意靜態伺服器提供儲存庫根目錄。

GitHub Pages：以 `main` 分支根目錄提供網站。本儲存庫不接觸現有 CCMS 程式、正式修繕資料或既有網站。

## 驗證

```sh
node --check app.js
node state.test.cjs
```

自動檢查涵蓋工作狀態轉換、人工確認、退回重送、輸入跳脫、搜尋篩選與重設。
